Comment se fait le paiement

Le règlement passe par Mobile Money — MTN MoMo ou Orange Money. Vous saisissez votre numéro, votre opérateur vous envoie une demande de confirmation sur votre téléphone, et vous validez avec votre code secret sur votre appareil.

ChatDocs OHADA ne vous demande jamais votre code Mobile Money, ni un numéro de carte. L'application ne les voit pas et n'en conserve aucun. Un règlement en espèces ou par virement reste possible : votre demande est alors activée par l'équipe.

Vos crédits s'ouvrent pour trente jours dès le paiement confirmé.
