Code Général des Impôts (Côte d'Ivoire)

Article 339. - Le taux normal de la taxe sur la valeur ajoutée est fixé à 18 %.

Ce taux s'applique à l'ensemble des opérations taxables pour lesquelles aucun autre taux n'est expressément prévu par la loi. La base d'imposition est constituée par le montant total des sommes réclamées à l'acquéreur.
