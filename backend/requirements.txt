# ChatDocs OHADA — dépendances du backend
#
# Python 3.11 ou 3.12. PAS 3.14 : les roues de psycopg2 n'existent pas
# encore pour cette version, et la compilation demande PostgreSQL en
# local — ce qui n'est pas raisonnable à demander pour lancer un projet.
#
#   py -3.11 -m venv .venv
#   .venv\Scripts\activate
#   pip install -r requirements.txt
#
# -----------------------------------------------------------------
# POURQUOI LES VERSIONS SONT FIGÉES
# -----------------------------------------------------------------
# Sans `==`, `pip install` livre les dernières versions du jour. Six
# mois plus tard, celui qui clone le dépôt obtient d'autres majeures et
# une application qui ne démarre plus — pour un dépôt de groupe, c'est
# la panne qui coûte le plus de temps à tout le monde.
#
# Ces versions sont celles sur lesquelles les 342 tests passent.
#
# Pour mettre à jour un paquet : changer sa ligne, relancer la suite de
# tests, et ne commiter que si elle passe.
#
# -----------------------------------------------------------------
# TOUT CE QUI EST IMPORTÉ DIRECTEMENT EST DÉCLARÉ ICI
# -----------------------------------------------------------------
# Y compris ce qui arrive déjà par transitivité. Une dépendance
# transitive peut disparaître à la prochaine mise à jour de ce qui
# l'apportait, et la panne survient alors sans qu'on ait rien changé.
